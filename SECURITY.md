# Security policy

## Reporting a vulnerability

Не публикуйте сведения об уязвимости, рабочие exploits, секреты или реальные скриншоты в
GitHub Issues. Используйте private vulnerability reporting репозитория. Если он недоступен,
свяжитесь с владельцем репозитория приватным каналом и передайте минимальный безопасный
пример воспроизведения.

В сообщении укажите затронутую версию или commit, влияние, условия эксплуатации и шаги
воспроизведения без персональных данных. Не проверяйте проблему на чужих системах и не
извлекайте данные, не необходимые для подтверждения.

## Supported versions

Пока проект не выпускает стабильные релизы, исправления безопасности применяются только к
последнему состоянию основной ветки.

## Operational guidance

Техническая модель угроз, обязательные настройки TLS, секретов, CORS и ограничения текущей
аутентификации описаны в [`docs/SECURITY.md`](./docs/SECURITY.md).
